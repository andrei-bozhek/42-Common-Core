# get_next_line

## 概要

get_next_line は、ファイルディスクリプタから1行ずつ読み込む
42 Common Core のプロジェクトです。

外部関数として `read`、`malloc`、`free` のみを使用し、
呼び出すたびに次の1行を返す関数を実装します。
このプロジェクトでは、static 変数、バッファを使った読み込み、
複数回の関数呼び出しにまたがるメモリ管理を学びます。

```c
char	*get_next_line(int fd);
```

改行文字 `\n` がある場合、返される文字列にはその改行文字も含まれます。
ファイルの末尾に `\n` がない場合も、最後の行を返します。
読み込むデータがなくなった場合、またはエラーが発生した場合は
`NULL` を返します。返された各行は、呼び出し側で解放する必要があります。

この実装は必須課題に対応しています。保存用の文字列は1つだけなので、
複数のファイルディスクリプタを交互に読み込む使い方には対応していません。

## アルゴリズム

まだ返していないデータを、`saved` という static ポインタで保持します。
このポインタの値は、関数の呼び出しが終わっても保持されます。

1. ファイルディスクリプタとバッファサイズを確認します。
2. `BUFFER_SIZE + 1` バイトの一時バッファを確保します。
3. `saved` にすでに `\n` があれば、読み込みを省略します。
   なければ、改行が見つかるか EOF に達するまで読み込み、
   データを `saved` に追加します。
4. 先頭行の領域を確保してコピーします。`\n` があれば、それも含めます。
5. 残りのデータを別の領域にコピーし、古い `saved` を解放します。
   残りは次回の呼び出しのために保持します。
6. 切り出した行を呼び出し側に返します。

この方法では、1回に読み込むサイズと行の長さを分けて扱えます。
1行を複数回に分けて読み込むことも、1回の読み込みに複数行が含まれることもあります。
残りを保存することで、読み込み済みのデータを失わずに次の呼び出しへ引き継げます。

このアルゴリズムを選んだ理由は、C の文字列を使った処理が分かりやすく、
メモリを確保・解放する場所を明示できるためです。
ファイル全体を先に読み込むのではなく、行を返すために必要な分だけ読み込みます。
一時バッファは読み込み終了後に解放し、保存データは置き換えるときや
エラーが発生したときに解放します。

一方で、長い行を組み立てる際には、メモリの確保とコピーを繰り返します。
バッファサイズが小さく固定されている場合、処理時間が行の長さの2乗に
比例することがあります。

## 使用方法

### コンパイル

Makefile は必要ありません。2つのソースファイルを使用するプログラムと一緒に
コンパイルします。以下のコマンドは、`get_next_line.c` があるディレクトリで
実行してください。

```sh
cc -Wall -Wextra -Werror -D BUFFER_SIZE=42 \
    main.c get_next_line.c get_next_line_utils.c -o program
```

`BUFFER_SIZE` は、1回の `read` で要求する最大バイト数です。
指定しない場合、ヘッダで定義された初期値 `42` が使われます。
`1`、`42`、`1024` などの正の値を指定してください。

### 実行例

次の例を `main.c` として保存し、上記のコマンドでコンパイルします。
ファイル名を渡すとそのファイルを開き、引数を省略すると標準入力から読み込みます。

```c
#include "get_next_line.h"
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int	main(int argc, char **argv)
{
	int		fd;
	char	*line;

	if (argc > 2)
		return (1);
	fd = STDIN_FILENO;
	if (argc == 2)
	{
		fd = open(argv[1], O_RDONLY);
		if (fd < 0)
			return (1);
	}
	line = get_next_line(fd);
	while (line)
	{
		printf("get_next_line returned: %s", line);
		free(line);
		line = get_next_line(fd);
	}
	if (argc == 2)
		close(fd);
	return (0);
}
```

ファイル名を指定して読み込む場合：

```sh
./program input.txt
```

標準入力から読み込む場合：

```sh
printf 'first\nsecond\n' | ./program
./program < input.txt
```

ループに入る前に `get_next_line` を呼び出し、最初の行を取得します。
ループ内では、現在の行を表示して解放してから、次の行を取得します。
`get_next_line` が `NULL` を返すとループを終了します。
プログラムがファイルを開いた場合は、最後にそのファイルを閉じます。
