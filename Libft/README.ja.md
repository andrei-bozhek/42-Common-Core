# Libft

## 概要

Libft は、42 Common Core で最初に取り組むライブラリのプロジェクトです。

このプロジェクトでは、メモリ操作、文字列処理、文字の判定、変換、出力、
連結リストを扱う基本的な関数を備えた、再利用可能な C ライブラリを実装します。

C 標準ライブラリにある関数の一部を再実装するとともに、
今後の 42 のプロジェクトで再利用する補助関数も作成します。

コンパイルすると、次のライブラリが生成されます。

`libft.a`

## ライブラリの内容

### 文字の判定と変換

| 関数 | 説明 |
|---|---|
| `ft_isalpha` | 英字かどうかを判定します。 |
| `ft_isdigit` | 10進数字かどうかを判定します。 |
| `ft_isalnum` | 英数字かどうかを判定します。 |
| `ft_isascii` | ASCII 文字集合の範囲内かどうかを判定します。 |
| `ft_isprint` | 表示可能な文字かどうかを判定します。 |
| `ft_toupper` | 小文字を大文字に変換します。 |
| `ft_tolower` | 大文字を小文字に変換します。 |

### 文字列関数

| 関数 | 説明 |
|---|---|
| `ft_strlen` | 文字列の長さを返します。 |
| `ft_strlcpy` | サイズ制限を設けて、文字列をバッファにコピーします。 |
| `ft_strlcat` | サイズ制限を設けて、文字列を別のバッファに追加します。 |
| `ft_strchr` | 指定した文字が最初に現れる位置を探します。 |
| `ft_strrchr` | 指定した文字が最後に現れる位置を探します。 |
| `ft_strncmp` | 指定した文字数を上限として、2つの文字列を比較します。 |
| `ft_strnstr` | 指定した範囲内で部分文字列を探します。 |
| `ft_strdup` | メモリを確保し、文字列の複製を返します。 |

### メモリ関数

| 関数 | 説明 |
|---|---|
| `ft_memset` | メモリ領域を指定したバイト値で埋めます。 |
| `ft_bzero` | メモリ領域をゼロで埋めます。 |
| `ft_memcpy` | メモリ領域を別の場所へコピーします。 |
| `ft_memmove` | コピー元とコピー先が重なる場合も、安全にコピーします。 |
| `ft_memchr` | メモリ領域から指定したバイト値を探します。 |
| `ft_memcmp` | 2つのメモリ領域を比較します。 |
| `ft_calloc` | メモリを確保し、ゼロで初期化します。 |

### 文字列処理と変換の補助関数

| 関数 | 説明 |
|---|---|
| `ft_atoi` | 文字列の先頭部分を整数に変換します。 |
| `ft_substr` | メモリを確保し、部分文字列を返します。 |
| `ft_strjoin` | メモリを確保し、2つの文字列を連結します。 |
| `ft_strtrim` | 文字列の両端から、指定した文字を取り除きます。 |
| `ft_split` | 文字列を分割し、末尾が NULL の文字列配列を返します。 |
| `ft_itoa` | 整数を文字列に変換し、新しく確保した領域に格納します。 |
| `ft_strmapi` | 各文字に関数を適用し、新しい文字列を作成します。 |
| `ft_striteri` | 文字列の各文字に関数を適用し、その場で変更します。 |

### ファイルディスクリプタへの出力

| 関数 | 説明 |
|---|---|
| `ft_putchar_fd` | 指定したファイルディスクリプタに1文字を出力します。 |
| `ft_putstr_fd` | 指定したファイルディスクリプタに文字列を出力します。 |
| `ft_putendl_fd` | 指定したファイルディスクリプタに文字列と改行を出力します。 |
| `ft_putnbr_fd` | 指定したファイルディスクリプタに整数を出力します。 |

### 連結リスト関数

ライブラリでは、次の単方向連結リストの構造体を使用します。

```c
typedef struct s_list
{
	void			*content;
	struct s_list	*next;
}	t_list;
```

### 連結リストを操作する関数

| 関数 | 説明 |
|---|---|
| `ft_lstnew` | 新しいノードを確保し、初期化します。 |
| `ft_lstadd_front` | リストの先頭にノードを追加します。 |
| `ft_lstsize` | リストのノード数を返します。 |
| `ft_lstlast` | リストの最後のノードを返します。 |
| `ft_lstadd_back` | リストの末尾にノードを追加します。 |
| `ft_lstdelone` | 渡された関数で内容を解放し、1つのノードを解放します。 |
| `ft_lstclear` | 指定したノードと、それ以降のすべてのノードを解放します。 |
| `ft_lstiter` | 各ノードの内容に関数を適用します。 |
| `ft_lstmap` | 各ノードの内容に関数を適用し、新しいリストを作成します。 |

## 使用方法

### コンパイル

次のコマンドを実行します。

```sh
make
```

`cc` と `-Wall -Wextra -Werror` を使用してソースファイルをコンパイルし、
次の静的ライブラリを生成します。

```text
libft.a
```

使用できる Makefile のルールは次のとおりです。

| コマンド | 説明 |
|---|---|
| `make` | `libft.a` をビルドします。 |
| `make clean` | オブジェクトファイルを削除します。 |
| `make fclean` | オブジェクトファイルと `libft.a` を削除します。 |
| `make re` | ライブラリを最初からビルドし直します。 |

### 実行例

ソースファイルにヘッダをインクルードします。

```c
#include "libft.h"
```

プログラムをコンパイルし、ライブラリをリンクします。

```sh
cc -Wall -Wextra -Werror main.c libft.a -o program
```

続いて実行します。

```sh
./program
```
