# ft_printf

## 概要

ft_printf は、42 Common Core のライブラリプロジェクトです。

可変個の引数の扱い方を学びながら、C 標準の `printf()` 関数の一部を再実装します。
書式に従った文字列を標準出力に書き込み、出力したバイト数を返します。
出力エラーが発生した場合は `-1` を返します。

コンパイルすると、次のライブラリが生成されます。

`libftprintf.a`

関数プロトタイプは次のとおりです。

```c
int ft_printf(const char *format, ...);
```

## 対応する変換指定子

| 変換指定子 | 説明 |
|---|---|
| `%c` | ヌル文字を含む1文字を出力します。 |
| `%s` | ヌル終端文字列を出力します。 |
| `%p` | ポインタを `0x` 付きの16進数で出力します。 |
| `%d` | 符号付き整数を10進数で出力します。 |
| `%i` | 符号付き整数を10進数で出力します。 |
| `%u` | 符号なし整数を10進数で出力します。 |
| `%x` | 符号なし整数を小文字の16進数で出力します。 |
| `%X` | 符号なし整数を大文字の16進数で出力します。 |
| `%%` | 引数を消費せずにパーセント記号を出力します。 |

文字列ポインタが NULL の場合は `(null)` を、`%p` に渡されたポインタが
NULL の場合は `(nil)` を出力します。テストに使用した Linux 環境の動作に
合わせています。

この実装は必須の変換指定子に対応しています。
ボーナス課題のフラグ、フィールド幅、精度指定には対応していません。

## 使用方法

### コンパイル

以下のコマンドは `ft_printf` ディレクトリで実行します。
C コンパイラ、`make`、`ar` が必要です。

```sh
make
```

`cc` と `-Wall -Wextra -Werror` を使用してソースファイルをコンパイルし、
次の静的ライブラリを生成します。

```text
libftprintf.a
```

使用できる Makefile のルールは次のとおりです。

| コマンド | 説明 |
|---|---|
| `make` | `libftprintf.a` をビルドします。 |
| `make clean` | オブジェクトファイルを削除します。 |
| `make fclean` | オブジェクトファイルと `libftprintf.a` を削除します。 |
| `make re` | ライブラリを最初からビルドし直します。 |

### 実行例

ソースファイルにヘッダをインクルードします。

```c
#include "ft_printf.h"

int main(void)
{
    int count;

    count = ft_printf("Hello %s! Number: %d, hex: %x\n", "42", 123, 255U);
    if (count == -1)
        return (1);
    ft_printf("Bytes written: %d\n", count);
    return (0);
}
```

この例を `main.c` として保存し、コンパイルしてライブラリをリンクします。

```sh
cc -Wall -Wextra -Werror main.c libftprintf.a -o program
```

続いて実行します。

```sh
./program
```

## アルゴリズムとデータ構造

### 書式文字列の解析

書式文字列を左から右へ1回走査します。通常の文字はそのまま出力します。
パーセント記号に変換指定子が続く場合は、指定子に応じた出力関数を呼び出します。

`va_start` で引数の読み取りを開始し、`va_arg` で変換指定子に対応する型の
値を取得し、`va_end` で読み取りを終了します。
変換指定子に応じて処理を振り分ける関数には `va_list` へのポインタを渡し、
変換を続けるたびに次の引数へ進めるようにしています。

各出力関数は、出力したバイト数を返します。失敗した場合は `-1` を返します。
解析処理は成功した結果を合計し、エラーが発生した場合は直ちに終了します。
`%c` で出力するヌル文字も1バイトとして数えます。

### 数値の変換

数値は再帰的に出力します。基数による除算で上位の桁を先に処理し、
余りを使って現在の桁を選びます。10進数では基数10、16進数では基数16を使用します。
16進数の大文字・小文字は、桁の選択に使う文字列によって決まります。
ゼロは1桁の数字として出力します。

符号付き10進数では、入力値を `long` に変換してから負の値の符号を反転します。
対象の Linux 環境では `long` が `int` より広いため、
`int` のオーバーフローを起こさずに `INT_MIN` を扱えます。
この環境では、NULL 以外のポインタを `unsigned long` に変換し、
`0x` の後に小文字の16進数で出力します。

### 設計上の選択

書式文字列、`va_list`、数値のカウンタ、定数の数字文字列を使用します。
各引数を取得した直後に処理して出力するため、ヒープ領域の確保や
追加のコンテナは必要ありません。また、元の `printf()` が行う
バッファリングの実装も省いています。

コードは役割に応じて、次のファイルに分けています。

| ファイル | 役割 |
|---|---|
| `ft_printf.c` | 可変長引数の準備、書式文字列の解析、変換処理の振り分け。 |
| `ft_print_common.c` | 文字、文字列、10進数の出力。 |
| `ft_print_base.c` | 16進数とポインタの出力。 |
| `ft_printf.h` | 共通の宣言と必要なヘッダ。 |
